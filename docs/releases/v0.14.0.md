## 中文

- **用量分析 → 本机用量** 默认以 Token 显示趋势和分布。选择趋势中的 **本机日志额度估算**，可查看所选日期内 5 小时和 7 天额度的观测变化及天数覆盖。
- 估算读取本机留存会话里的额度快照。切换账号后，同一数据源中保留的旧会话仍参与统计。每个窗口的百分点以各自的账号额度为基准，读数可能包含其他设备的用量。重叠观测只计一次，无法归到同一天的变化不计入日合计。

手动升级前请退出 Pulse，备份完整程序目录，并在替换程序时保留 `data`。应用使用 Ed25519 验证更新清单，再核对包摘要。Windows EXE 暂无 Authenticode 发布者签名。 [数据访问与签名说明](../TRUST.md)

## English

- **Usage analysis → Local usage** shows trends and breakdowns in tokens by default. Choose **Local quota estimate** in the trend controls to see observed changes and date coverage for the 5-hour and 7-day windows in the selected range.
- The estimate uses quota snapshots saved in local session logs. Sessions retained in the same data source still count after an account switch. Percentage points refer to each account’s own allowance, and readings can reflect activity on other devices. Overlapping observations count once, and changes that cannot be placed on a single day are excluded from daily totals.

For a manual upgrade, quit Pulse, back up the complete program directory, and retain `data` when replacing the program. The app verifies the update manifest with Ed25519 and checks the package digest. The Windows EXE currently has no Authenticode publisher signature.
