# Codex Pulse 0.6.1

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.6.1) · [Demo / 演示](https://zhulongqihan.github.io/codex-pulse/)

## 中文

修复个人额度节奏的一处显示边界：当一个额度窗口已经用尽，而另一个窗口的预计触顶区间下界恰好为零时，紧凑提示现在优先显示“额度已用尽”。仍然保留各窗口自己的读数，不将预测当作已发生的消耗。

产品首页的版本号随软件清单同步更新。GitHub 现已开放[讨论区](https://github.com/zhulongqihan/codex-pulse/discussions)，欢迎使用体验、问题和建议；[问题表单](https://github.com/zhulongqihan/codex-pulse/issues/new/choose)与[反馈指南](https://github.com/zhulongqihan/codex-pulse/blob/main/SUPPORT.md)也已完善。

这是兼容修复，沿用现有数据和偏好。可使用软件内的签名更新，或完整解压便携包、从托盘退出后替换程序并保留 `data`。0.6.0 的标签与安装包继续保留。

右上角伴随提示仍面向 Windows 商店版 Codex。样本充分时才提供触顶趋势区间，不保证剩余工作时长；原 MCP 页的输入框由宿主管理，新卡片没有输入框。完整说明见[中文指南](https://github.com/zhulongqihan/codex-pulse/blob/main/docs/CODEX_INTEGRATION.md)。

## English

Fixes an edge case in personal quota pace: when one quota window is exhausted and another forecast has a lower time bound of zero, the compact indicator now prioritizes the exhausted window. Individual window readings remain available; a projection is not treated as observed consumption.

The product homepage now reads its version from the application manifest. [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions) are open for experiences, questions, and ideas, with improved [issue forms](https://github.com/zhulongqihan/codex-pulse/issues/new/choose) and a bilingual [feedback guide](https://github.com/zhulongqihan/codex-pulse/blob/main/SUPPORT.md).

This compatible fix retains existing data and preferences. Use the signed updater, or extract the complete portable archive, quit from the tray, replace program files, and keep `data`. The 0.6.0 tag and packages remain available.

Corner following still targets the Microsoft Store edition of Codex for Windows. Estimates require sufficient samples and do not guarantee working time. The original MCP page's composer belongs to the host; the new card has no input box. See the [English guide](https://github.com/zhulongqihan/codex-pulse/blob/main/docs/CODEX_INTEGRATION.en.md).
