## 中文

- 如果额度刷新失败或读数过期，只要原额度窗口仍在进行，配速提示就会显示上次额度已用百分比和当前周期进度。
- 顶部 ⓘ 会标明额度百分比来自上次读数。当前周期进度按重置时刻、窗口时长和当前时间计算。取得新读数后才会恢复配速建议。
- 有额度值但缺少更新时间时，省略更新时间。

手动升级前请退出 Pulse，备份完整程序目录，并在替换程序时保留 `data`。应用使用 Ed25519 验证更新清单，再核对包摘要。[数据访问与签名说明](../TRUST.md)

## English

- If a quota refresh fails or the reading is stale, the pacing hint keeps showing the last quota-used percentage and current cycle progress while the original quota window is still active.
- The hint beside the title labels the quota percentage as the last reading. Cycle progress uses the window duration, reset time and current time. Pacing recommendations resume with a fresh reading.
- When a quota value is available and its update time is unknown, the update time is omitted.

For a manual upgrade, quit Pulse, back up the complete program directory and retain `data` when replacing the program. The app verifies the update manifest with Ed25519 and checks the package digest. [Data access and signing details](../TRUST.md#english)
