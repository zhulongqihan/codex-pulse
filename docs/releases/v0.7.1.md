# Codex Pulse 0.7.1

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.7.1)

## 中文

修复 Codex 主窗口恢复或最大化后没有系统标题栏时，右上角伴随提示无法出现的问题。继续验证官方商店包身份，并排除子窗口、工具窗和浮层。

修复便携升级覆盖已准备插件文件、导致 Codex 下次启动读取占位命令而无法显示插件的问题。插件模板现在内嵌于程序，正常启动可幂等准备或修复；便携包不再覆盖运行时插件目录。已有有效的数据目录绑定会保留，显式重新添加才更换绑定。MCP 读取模式继续不初始化桌面、不修写插件、不请求账号。

设置明确区分“右上角跟随”与“登录时启动 Pulse”，显示系统启动项的实际状态，并可从跟随设置直接定位已有登录启动开关。需要电脑重启后自动运行时，请开启登录启动；单独打开 Codex 不会启动已退出的 Pulse。

保留原有数据和外观偏好。旧 Codex 窗口若仍缓存失败的插件，可在设置中重新添加该插件后重试。欢迎通过 [Issues](https://github.com/zhulongqihan/codex-pulse/issues) 或 [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions) 反馈使用体验。

## English

Fixes the corner companion missing when the real Codex window is restored or maximized without a system caption. Official Store package identity remains verified; child, tool and overlay windows remain excluded.

Fixes portable upgrades overwriting prepared plugin files and leaving placeholder commands that prevent the plugin opening after a Codex restart. Templates are now embedded, normal startup can prepare or repair files idempotently, and the portable archive no longer overwrites the runtime plugin directory. Valid existing data bindings are retained; explicitly adding the plugin again can change them. Read-only MCP mode still does not initialize the desktop, repair plugin files or query an account.

Settings distinguish corner following from Start Pulse at sign-in, show the actual startup-entry state, and link to the existing sign-in switch. Enable sign-in startup for automatic operation after a restart. Opening Codex alone does not launch a Pulse instance you have quit.

Existing data and appearance preferences are retained. A running Codex window retaining a failed plugin cache may need the plugin added again before retrying. Feedback is welcome in [Issues](https://github.com/zhulongqihan/codex-pulse/issues) or [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions).
