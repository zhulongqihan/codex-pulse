# Codex Pulse 0.9.0

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.9.0)

## 中文

- 主会话列表支持按标题、会话 ID、模型和项目搜索已加载的会话；命中子代理时保留父子会话组，清空搜索即可恢复原列表。搜索不重新扫描日志，也无法找回未留存的记录。
- 模型页缺少历史额度样本时显示原因，避免空灰条被误认为仍在加载；真实零值仍正常显示。
- 使用帮助补充额度不可用、Token／参考成本／账号额度的区别及恢复入口。
- 展开桌面浮窗在缺少额度读数时压缩无用留白，保留状态说明与检查账号等可用操作。
- Codex 插件补充本轮每日观测与带来源的重置预告，并可打开对应的 Pulse 详情；继续只读本机快照，不独立查询账号或发起模型请求。
- 明确插件语言和外观的跟随规则，将桌面浮窗、右上角提示和 Codex 插件入口集中到同一设置分区。

升级保留 `data` 中的本地统计、偏好与同账号观测。Codex 宿主缓存的插件可能需要重新安装；宿主管理的面板容器与输入框仍由 Codex 控制。

欢迎在 [Issues](https://github.com/zhulongqihan/codex-pulse/issues) 报告问题，或在 [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions) 分享建议。

## English

- Search loaded sessions by title, session ID, model and project in the main session list. A matching subagent retains its parent and sibling group; clearing the query restores the original list. Search does not rescan logs or recover records that are no longer retained.
- Explain missing historical quota samples on the Models page instead of drawing empty gray tracks that resemble loading. Actual zero values remain visible.
- Expand usage help with quota availability, the differences between local tokens, reference costs and account quota, and relevant recovery actions.
- Keep the expanded desktop widget compact when quota readings are unavailable, while retaining its status and useful account-recovery actions.
- Include the current cycle's daily observations and sourced reset notices in the Codex plugin, with links to the corresponding Pulse details. The plugin continues to read local snapshots without independent account queries or model requests.
- Explain how the plugin follows language and appearance preferences, and group the desktop widget, corner companion and Codex plugin entries in one settings section.

Upgrades retain local statistics, preferences and same-account observations in `data`. Plugins cached by Codex may need reinstallation. The host still controls its panel container and composer.

Report problems in [Issues](https://github.com/zhulongqihan/codex-pulse/issues) or share ideas in [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions).
