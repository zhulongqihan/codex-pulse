## 中文

- 点「刷新账号读数」会立即读取配额。60 秒间隔用于后台采样，普通失败后也可以马上手动重试。
- 同一账号已有查询时，共用这次结果。服务端限流时，界面显示等待时间，Pulse 会在可以查询时执行一次已安排的刷新。

## English

- Refresh account readings checks quota immediately. The 60-second interval applies to background sampling, and you can retry a regular failure immediately.
- Checks already running for the same account share one result. If the server is rate limiting, Pulse shows the wait and runs one requested refresh when it can.
