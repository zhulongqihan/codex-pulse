# Codex Pulse 0.10.0

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.10.0)

## 中文

- 仪表盘集中展示当前额度、个人重置时间、配速判断与今日 API 参考成本。本机今日 Token 和会话入口仍可直接查看；配速依据及构成明细按需展开。
- 左侧新增“用量分析”，承接所选时段的汇总、趋势、项目／模型分布及 XLSX／Markdown 导出。历史范围与今天的读数分别计算，切换页面不把时段总计当作今日用量。
- 账号、订阅、Credits、重置详情和预告集中到已有账号入口，减少首页重复信息。账号区按需打开，并保留原有恢复、重试和重置服务入口。
- 清爽与刻度使用相同的信息顺序；六种语言、窄窗口与键盘导航继续可用。图表的日期选择、单位切换、数据表和全屏保留在分析页。

API 参考成本按本机记录与模型单价估算，**不是订阅账单、Credits 扣款或额外收费**。官方账号额度与本机 Token 分别统计；缺少读数或价格时保持未知。配速依据当前实际返回的窗口，不保证连续工作时长。

升级保留 `data` 中的统计、会话索引、偏好及同账号观测。此次调整不改变统计口径、额度采样或导出数据格式，不需要清空缓存。模型、按日、按月、项目和会话仍保留各自的专题入口。

欢迎在 [Issues](https://github.com/zhulongqihan/codex-pulse/issues) 报告问题，或在 [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions) 分享建议。

## English

- The dashboard focuses on current quota, personal reset time, pacing guidance and today's API reference cost. Today's local tokens and session entry remain easy to find, with pacing evidence and breakdowns available on demand.
- A new **Usage analysis** item in the sidebar contains selected-period totals, trends, project/model distributions and XLSX/Markdown exports. Today's readings remain separate from the historical range; changing pages does not present a period total as today's usage.
- Account identity, subscription, Credits, reset details and notices are reached through the existing account entry, reducing repeated dashboard content. The account area opens on demand and retains recovery, retry and reset-service actions.
- Clear and Meter share the same information order, with six languages, narrow-window layouts and keyboard navigation. Date selection, chart units, the data table and fullscreen viewing remain available in Usage analysis.

API reference costs are estimates from local records and model unit prices, **not subscription bills, Credits deductions or extra charges**. Official account quota and local tokens remain separate measurements. Missing readings or prices stay unknown. Pacing uses the window actually returned and does not guarantee uninterrupted working time.

Upgrades retain statistics, session indexes, preferences and same-account observations in `data`. This change does not alter accounting rules, quota sampling or exported data formats, and does not require clearing caches. Sessions, models, daily, monthly and projects retain their specialized entries.
