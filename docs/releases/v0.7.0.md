# Codex Pulse 0.7.0

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.7.0) · [Demo / 演示](https://zhulongqihan.github.io/codex-pulse/)

## 中文

本版将悬浮窗和主界面统一为额度配速：直接查看还剩多少额度、多久到个人周期重置，以及额度消耗是否快于时间进度。状态采用“从容用／节奏均衡／用量偏快”，并列出实际额度与时间基线。日均或每小时分配只是把现有余量均摊到重置前的参考，不是每天新增额度、请求数或保证可工作时长。

桌面浮窗保留拖动、折叠、置顶与位置偏好；工作台保留独立今日统计、完整区间分析、会话回放、清爽／刻度与六语言。额度百分比暂未变化时，基本配速信息仍然可用，不再依赖触顶预测才能看到主要数字。

本轮每日小记录明确区分已观测增长、部分覆盖与没有记录；首次升级不会补造整周历史。临近重置且余量较多时可提示安排计划内任务；只有足够新鲜且可辨的趋势支持时才展示重置余量的条件区间。Token 和 API 参考价格不参与账号额度换算。

新重置预告可在后台更新，通过醒目入口与置顶提示展示来源、预计时段及待确认状态。资讯来自第三方，全局消息不表示你的账号已经重置；个人周期结束时间独立显示，旧消息、过期或撤回的提示不会反复当作新预告。

右上角伴随窗改为响应 Windows 窗口移动事件，合并位置更新并减少重复身份检查，改善拖动时的跳步。仍只跟随经校验的 Windows 商店版 Codex，不改变客户端安装或聊天内容。

沿用现有数据和设置，新增观测与提醒状态保存在本地 `data`。可使用签名更新，或从托盘退出后完整替换便携程序文件并保留 `data`。0.6.2 未作为独立版本发布，其中修正已纳入本版。欢迎到 [Issues](https://github.com/zhulongqihan/codex-pulse/issues) 或 [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions) 提交体验和建议。

## English

The corner card, desktop widget and workspace now share quota pacing: see remaining quota, time until the personal window reset, and whether consumption is ahead of the window's time progress. Plain-language advice includes the quota and time baseline. A daily or hourly allocation simply spreads the current remainder until reset; it is not a daily refill, request allowance or guarantee of working time.

The desktop widget retains dragging, expansion, pinning and position preferences. The workspace keeps independent daily totals, full-range analytics, session replay, Clear/Meter and six languages. Flat quota readings no longer make the basic summary depend on an unavailable depletion forecast.

Daily observations distinguish recorded changes, partial coverage and missing data; upgrading does not manufacture an entire cycle of history. Surplus near reset can suggest tasks already in your plan. A remaining-at-reset range appears only when fresh, measurable trends support that conditional projection. Tokens and API reference prices are never converted into account quota.

Reset notices can update in the background and display a visible source, expected window and unconfirmed status. They are third-party global information, not confirmation that your personal quota has reset. Personal window expiry remains separate, and old, expired or withdrawn items are not repeatedly presented as new notices.

The corner companion now responds to Windows location events, coalesces updates and avoids repeated identity checks during movement. It still follows only verified Microsoft Store Codex windows without modifying the client installation or chat content.

Existing data and preferences are retained. New observation and notice state stays in local `data`. Use the signed updater, or quit from the tray, replace the complete portable program files and keep `data`. Version 0.6.2 was not released separately; its fixes are included here. Feedback is welcome in [Issues](https://github.com/zhulongqihan/codex-pulse/issues) and [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions).
