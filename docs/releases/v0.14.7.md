# Codex Pulse 0.14.7

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.14.7)

## 中文

- 纸册八个标签页按左右书页重新排版。仪表盘左页显示额度和配速，右页显示今日用量；分析和账表将筛选、汇总与图表或明细分放两页。窄窗或矮窗自动切换单页。
- 账号额度改用抽屉查看，打开时书页和内容位置不变。
- 纸册仪表盘的配速说明只显示额度消耗与周期进度、重置时刻与时区、最近更新时间。移除「查看配速依据」，重置预告默认折叠。

手动升级前请退出 Pulse，备份完整程序目录，并在替换程序时保留 `data`。应用使用 Ed25519 验证更新清单，再核对包摘要。[数据访问与签名说明](../TRUST.md)

## English

- All eight Paper tabs use a two-page layout in wide windows. The dashboard puts quota and pacing on the left and today's usage on the right. Analysis and ledgers place filters and totals on one page and charts or records on the other. Narrow or short windows use a single sheet.
- Account quota opens in a drawer and the spread stays in place.
- The Paper dashboard pacing tooltip keeps quota used and cycle elapsed, reset time with its time zone, and the last successful update. The extra pacing evidence section is removed, and reset forecasts start collapsed.

For a manual upgrade, quit Pulse, back up the complete program directory and retain `data` when replacing the program. The app verifies the update manifest with Ed25519 and checks the package digest. [Data access and signing details](../TRUST.md#english)
