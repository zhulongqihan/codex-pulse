## 中文

- 用户和助手的长消息先显示预览，点击“显示全文”再渲染完整 Markdown；加载中的占位内容也使用预览，避免首次打开就显示整段长正文。普通短消息仍完整显示。
- 全文操作放在正文前，展开时收起入口与键盘焦点保持可见，可以直接再次收起。
- 复制仍包含整段原文，搜索仍可找到预览之外的内容。清除搜索后，恢复原先的预览或主动展开状态；原始 JSONL 和回合导航继续可用。

升级保留 `data` 中的本地记录、偏好与同账号观测，统计和导出格式保持兼容。帮助与反馈、首次使用引导和合成工作情境继续保留。原始会话文件保持只读；主动展开特别长的消息仍需渲染完整内容。

Windows EXE 当前尚无 Authenticode 发布者签名；更新清单签名与包摘要验证是独立机制。[完整说明](../TRUST.md)。

## English

- Long user and assistant messages open as previews. Choose **Show full text** to render their complete Markdown; loading placeholders use the preview too. Ordinary short messages remain complete.
- The full-text control appears before the body, keeping the collapse action and keyboard focus in view when a message expands.
- Copying still includes the complete original text, and search finds content beyond the preview. Clearing a search restores the previous preview or explicitly expanded state. Raw JSONL and turn navigation remain available.

Upgrades retain local records, preferences and same-account observations in `data`, with compatible accounting and export formats. Help & feedback, first-use guidance and synthetic work scenarios remain available. Original session files stay read-only; explicitly expanding a very long message still renders its complete content.

The Windows EXE currently has no Authenticode publisher signature; update-manifest signatures and package digest verification are separate mechanisms. [Details](../TRUST.md#english).

Report problems in [Issues](https://github.com/zhulongqihan/codex-pulse/issues) or share actual experiences in [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions). Never send authentication files or raw conversations.
