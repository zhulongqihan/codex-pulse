# Codex Pulse 0.14.6

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.14.6)

## 中文

- 标题栏配速浮窗移除两处用尽提醒和「额度窗口」明细。查看消耗详情可进入主窗口。
- 刷新冷却期间显示静态图标和重试倒计时。倒计时结束后可点击刷新，刷新过程中图标保持静止。

手动升级前请退出 Pulse，备份完整程序目录，并在替换程序时保留 `data`。应用使用 Ed25519 验证更新清单，再核对包摘要。[数据访问与签名说明](../TRUST.md)

## English

- Remove two depletion warnings and the quota-window breakdown from the title-bar pacing panel. Open usage details to see more in the workspace.
- Show a static icon and retry countdown during cooldown. The refresh action becomes available when the countdown ends, and the icon stays still during refresh.

For a manual upgrade, quit Pulse, back up the complete program directory and retain `data` when replacing the program. The app verifies the update manifest with Ed25519 and checks the package digest. [Data access and signing details](../TRUST.md#english)
