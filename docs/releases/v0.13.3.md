## 中文

- 纸册仪表盘在宽窗中将当前额度、重置时间与配速放在左页，今日本机 Token、API 参考成本、官方额度观测、构成和分析入口放在右页。额度窗口的余量和重置时间可以并排查看。
- 完整配速详情在两页下方展开，可查看窗口判断、观察依据和重置预告。窄窗按单列连续滚动。
- 本机用量、参考成本和官方额度观测继续分别显示。纸册的背景、字体和已有外观偏好延续，清爽与刻度仍可在 **设置 → 外观** 选择。

手动升级前退出 Pulse 并备份完整程序目录，保留 `data` 后替换程序。Windows EXE 当前没有 Authenticode 发布者签名，应用使用 Ed25519 验证更新清单并核对包摘要。[数据访问与签名说明](../TRUST.md)。

## English

- In wide windows, the Paper dashboard puts current quota, reset times and pacing on the left page. Today's local tokens, API reference cost, official quota observations, breakdown and analysis links appear on the right. Each quota window keeps its remaining allowance next to its reset time.
- Full pacing details open below both pages and include window assessments, observation evidence and reset notices. Narrow windows use a single scrolling column.
- Local usage, reference cost and official quota observations remain separate. Paper retains its background, typography and appearance preferences. Clear and Meter are available under **Settings → Appearance**.

For manual upgrades, quit Pulse and back up its complete directory before replacing the program while retaining `data`. The Windows EXE currently has no Authenticode publisher signature. The app verifies the update manifest with Ed25519 and checks the package digest. [Data access and signing details](../TRUST.md#english).
