## 中文

- 打开 Pulse 就能查看账号额度和今日本机用量。两项随各自数据返回分别更新，今日本机 Token 优先显示。
- 清爽、刻度和纸册都默认收起今日构成。窄窗把主要读数放在前面，配速细节仍可从首页展开。
- 仪表盘、用量分析和会话作为常用入口。点击工具栏的「使用帮助」可查看读数说明、检查数据来源或创建快捷方式。

手动升级前请退出 Pulse，备份完整程序目录，并在替换程序时保留 `data`。应用使用 Ed25519 验证更新清单，再核对包摘要。[数据访问与签名说明](../TRUST.md)

## English

- Open Pulse to see account quota and today's local usage. Each updates as its data arrives, and local tokens lead the usage summary.
- Clear, Meter and Paper keep today's token breakdown collapsed by default. Narrow windows prioritize the main readings and keep pacing details accessible from the dashboard.
- Dashboard, Usage analysis and Sessions are the main destinations. Open **Getting started** in the toolbar for reading guidance, source settings and shortcut creation.

For a manual upgrade, quit Pulse, back up the complete program directory and retain `data` when replacing the program. The app verifies the update manifest with Ed25519 and checks the package digest. [Data access and signing details](../TRUST.md#english)
