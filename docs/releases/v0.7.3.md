# Codex Pulse 0.7.3

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.7.3)

## 中文

修复 0.7.2 在程序重启、首次初始化账号范围时意外清空同账号连续配速样本的问题。现在先核对持久记录的账号，再更新界面投影；已有的同账号样本可继续用于观测。真实切换账号仍会清除旧账号投影，并拒绝旧请求的迟到结果。

本机用量账本和外观偏好继续保留。补丁保留仍存在的真实观测，不补造缺失样本，也不合并其他账号的历史。样本不足或过期时仍不会生成预测。

包含 [0.7.2 的界面、账号同步和更新恢复提示改进](https://github.com/zhulongqihan/codex-pulse/blob/v0.7.3/docs/releases/v0.7.2.md)。欢迎在 [Issues](https://github.com/zhulongqihan/codex-pulse/issues) 报告问题，或在 [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions) 分享建议。

## English

Fixes version 0.7.2 clearing persisted observations for the same account when initializing the account scope after an application restart. The stored account is now checked before interface projections are invalidated, allowing existing observations to continue. Switching accounts still clears old account projections and rejects late responses from earlier requests.

Local usage records and appearance preferences are retained. The patch preserves observations that still exist; it does not invent missing samples or merge another account's history. Insufficient or stale observations still produce no forecast.

Includes the [interface, account synchronization and update recovery improvements from 0.7.2](https://github.com/zhulongqihan/codex-pulse/blob/v0.7.3/docs/releases/v0.7.2.md). Report problems in [Issues](https://github.com/zhulongqihan/codex-pulse/issues) or share ideas in [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions).
