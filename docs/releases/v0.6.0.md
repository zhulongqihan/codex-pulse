# Codex Pulse 0.6.0

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.6.0) · [Interactive preview / 交互演示](https://zhulongqihan.github.io/codex-pulse/)

## 中文

Codex 右上角现在可以显示统一软件图标与个人额度节奏。点击后展开无输入框卡片，查看当前窗口的预计触顶区间、与重置的先后关系，以及今日本机 Token 的项目／模型来源。切换到其他程序时，伴随窗口隐藏；清爽与刻度均可使用。

### 使用

1. 完整解压 Windows x64 便携包，运行 `CodexPulse.exe`，或使用现有的签名更新功能。
2. 在设置中开启 **Codex 右上角节奏提示**，保持 Pulse 运行，并切到 Windows 商店版 Codex 客户端。
3. 点击状态条展开卡片；按 Esc、点外部或关闭按钮收起。需要完整历史时打开详情。

右上角跟随目前仅支持 Windows 商店版 Codex。它是独立伴随窗口，不修改 Codex 安装文件；最小化、失去前台、空间不足或无受支持客户端时隐藏。设置可查看未显示原因。原有 MCP 侧栏入口继续保留，其底部输入框由宿主管理，无法可靠隐藏；新卡片没有输入框。

### 数据边界

- 额度节奏来自连续官方观测，按账号、工作区、来源、真实窗口时长与重置时间分别采样。至少 4 个有效点、跨度至少 15 分钟，且有足够正消耗后，才给保守时间区间。
- 区间是近期消耗持续时的触顶趋势，不保证可工作时长、请求次数或实际触顶时刻。量化误差与近期变化会扩宽区间。
- 缺少样本、无变化、消耗缓慢、陈旧、过期均有独立状态。换账号、重置、负增量或超过 10 分钟的间隔重新分段；超过约 6 分钟未更新时不继续预测。
- 采样默认约每 60 秒只读查询，错误与限流时冷却，不调用模型，也不启用逐会话 Credits。主工作台的“启动窗口”仍是独立、需确认且可能消耗额度的操作。
- 本机今日项目／模型占比只统计本机 Token；不能换算成个人额度。账号官方读数可能包含其他设备消耗。
- 观测保存在原 `data` 目录，身份只保留本地哈希；节奏卡片与 MCP 快照不包含身份哈希、认证信息或原始会话正文。

产品首页提供中英文说明与真实组件的合成演示，可切换预测、采样中、陈旧、清爽和刻度。公开演示不访问本机账号与文件，不把示例时间冒充真实预测。

升级时保留 `data`。手动替换程序前请从托盘退出；移动文件夹后重新创建快捷方式并重新添加 MCP 插件。需要 WebView2 Runtime；无需安装 Node.js 或 Rust。[完整安装说明](https://github.com/zhulongqihan/codex-pulse/blob/main/docs/CODEX_INTEGRATION.md)。

## English

Codex can now have a compact corner indicator with the shared app icon and your personal quota pace. Click to expand a card without a text box: see a range for reaching the current window's limit, its relation to reset, and today's local token sources by project/model. The companion hides when you switch to another app. Clear and Meter are both available.

### Use

1. Extract the complete Windows x64 portable archive and run `CodexPulse.exe`, or use the existing signed updater.
2. Enable the **Codex corner pace indicator** in settings, keep Pulse running, and switch to the Microsoft Store edition of Codex for Windows.
3. Click the indicator to expand; press Esc, click outside, or use the close button to dismiss. Open Details for full history.

Corner following currently supports only the Microsoft Store edition of Codex for Windows. It is an independent companion surface and does not modify Codex installation files. It hides when minimized, inactive, short of space, or without a supported client. Settings explain hidden states. The existing MCP sidebar entry remains; its host-owned composer cannot be reliably hidden. The new corner card has no input box.

### Data boundaries

- Quota pace uses consecutive official observations isolated by account, workspace, source, actual window duration, and reset time. Conservative ranges require at least 4 valid points spanning at least 15 minutes and significant positive consumption.
- A range describes the trend if recent consumption continues. It does not guarantee working time, request counts, or an actual time of exhaustion. Quantization and recent variation widen the range.
- Missing samples, idle, slow, stale, and expired readings have explicit states. Account changes, resets, decreasing consumption, or gaps over 10 minutes start new segments; readings older than about 6 minutes stop the forecast.
- Sampling reads existing quota about every 60 seconds by default, with cooldowns for errors and rate limits. It makes no model requests and does not enable per-session Credits. Activate window in the main workspace remains a separate, explicitly confirmed action that may consume quota.
- Today's local project/model shares measure local tokens only, never personal quota. Official account readings may include consumption from other devices.
- Observations remain in the existing `data` directory, with only a local identity hash. Pace and MCP snapshots contain no identity hash, authentication information, or raw conversation bodies.

The product homepage offers Chinese/English information and an interactive demo of the actual components. Switch forecast, sampling, stale, Clear, and Meter states with synthetic data only. The public demo accesses no local account or files and never presents example times as your real forecast.

Keep `data` when upgrading. Quit from the tray before manually replacing program files. Recreate shortcuts and re-add the MCP plugin after moving the folder. Requires WebView2 Runtime; Node.js and Rust are not needed. [Full installation guide](https://github.com/zhulongqihan/codex-pulse/blob/main/docs/CODEX_INTEGRATION.en.md).
