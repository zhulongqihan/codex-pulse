# Codex Pulse 0.13.0

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.13.0)

## 中文

- 在 **设置 → 外观** 选择清爽、刻度或纸册。纸册工作台使用带纹理的书页和横向纸签，仪表盘可同时查看本轮额度、配速与今日用量。用量分析、会话回放和导出等功能在三种外观中均可使用。
- 浅色、深色或系统模式、密度与动效可单独设置。切换外观时保留当前工作状态。
- 纸册悬浮窗可以收起查看当前状态，或展开查看周期进度、配速依据与今日摘要。浮窗默认跟随主窗，在 **设置 → 桌面与 Codex** 可选择独立外观。
- 支持 MCP Apps 的 Codex 客户端可使用纸册面板。面板可跟随 Pulse 或单独选择外观，宿主容器与输入框由 Codex 管理。

升级保留 `data` 中的本地记录与偏好。手动升级或迁移时先退出 Pulse，备份完整程序目录，再保留 `data` 更新程序。原始会话保持只读。

Windows EXE 当前尚无 Authenticode 发布者签名。更新清单使用 Ed25519 签名，更新包通过摘要验证。[完整说明](../TRUST.md)。

## English

- Choose Clear, Meter or Paper under **Settings → Appearance**. Paper uses textured pages and horizontal tabs. Its dashboard brings current quota, pacing and today's usage together. Usage analysis, session replay and exports are available in all three styles.
- Light, dark and system modes, density and motion can be configured independently. Switching styles preserves your working state.
- Collapse the Paper widget to see current status, or expand it for cycle progress, pacing evidence and today's summary. The widget follows the workspace by default and can use its own style under **Settings → Desktop & Codex**.
- Use the Paper panel in Codex clients with MCP Apps support. It can follow Pulse or use a panel-only style. Codex controls the host container and composer.

Upgrades retain local records and preferences in `data`. For manual upgrades or relocation, quit Pulse first, back up the complete application directory, and retain `data` while replacing the program. Original conversations remain read-only.

The Windows EXE currently has no Authenticode publisher signature. The update manifest uses an Ed25519 signature, and the update package is checked against its digest. [Details](../TRUST.md#english).

Report problems in [Issues](https://github.com/zhulongqihan/codex-pulse/issues) or share experiences in [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions). Keep authentication files and raw conversations private.
