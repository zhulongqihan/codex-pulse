# Codex Pulse 0.14.1

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.14.1)

## 中文

- 从 Codex 标题栏打开「本轮配速」时，Windows 不再为面板绘制亮色外框。配速面板使用单层圆角和柔和阴影，纸册主题去除重复描边。
- 长内容使用与面板配色一致的滚动条，底部刷新和详情入口保持可见。

手动升级前请退出 Pulse，备份完整程序目录，并在替换程序时保留 `data`。应用使用 Ed25519 验证更新清单，再核对包摘要。Windows EXE 暂无 Authenticode 发布者签名。 [数据访问与签名说明](../TRUST.md)

## English

- The pacing panel opened from the Codex title bar uses one rounded surface with a soft shadow. This removes the bright Windows outline and the extra frame in Paper mode.
- Long content uses a scrollbar styled for the panel. Refresh and Details stay visible at the bottom.

For a manual upgrade, quit Pulse, back up the complete program directory, and retain `data` when replacing the program. The app verifies the update manifest with Ed25519 and checks the package digest. The Windows EXE currently has no Authenticode publisher signature. [Data access and signing details](../TRUST.md#english)
