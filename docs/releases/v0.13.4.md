# Codex Pulse 0.13.4

## 中文

- **用量分析 → 官方额度记录** 在消耗汇总下显示所选日期中有多少天具备足够读数来计算消耗。样本不足与未观测日期显示未知，读数未变化的日期计入有可比观测的天数。
- 本地还有其他账号或来源的额度历史时，页面会提示如何切回对应的 Codex 账号或 Pulse 数据来源。每个账号与来源分别统计。
- 周额度与短时额度各自用百分点显示。同一窗口的可比读数从已用 20% 变成 28%，就记为观测消耗 8 个百分点。

手动升级前请退出 Pulse，备份完整程序目录，并在替换程序时保留 `data`。应用使用 Ed25519 验证更新清单，再核对包摘要。Windows EXE 暂无 Authenticode 发布者签名。 [数据访问与签名说明](../TRUST.md)

## English

- **Usage analysis → Official quota history** shows how many days in the selected range had enough readings to calculate consumption. Days with insufficient or missing samples stay unknown. A day with comparable readings that did not change counts toward the coverage.
- When quota history from another account or source is saved locally, the page explains how to switch back to that Codex account or Pulse data source. Each account and source has its own total.
- The long and short quota windows report consumption separately in percentage points. If comparable readings for one window go from 20% used to 28% used, the recorded consumption is 8 percentage points.

For a manual upgrade, quit Pulse, back up the complete program directory, and retain `data` when replacing the program. The app verifies the update manifest with Ed25519 and checks the package digest. The Windows EXE currently has no Authenticode publisher signature. [Data access and signing details](../TRUST.md#english)
