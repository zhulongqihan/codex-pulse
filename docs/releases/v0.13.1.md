# Codex Pulse 0.13.1

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.13.1)

## 中文

- 优化纸册仪表盘的字体与排版：导航、指标名称和读数使用协调的 UI 字体，主数字更克制，周期、更新时间和统计口径更易阅读。
- 调整纸册悬浮窗的文字层级与间距，保留收起／展开、配速依据、状态说明和独立外观选择。
- 保留纸册背景与配色，以及清爽、刻度两种外观。额度历史、本机记录与原有偏好继续保留。

在 **设置 → 外观** 选择纸册；悬浮窗默认跟随主窗，也可在 **设置 → 桌面与 Codex** 单独选择。

手动升级前退出 Pulse 并备份完整程序目录，保留 `data` 更新程序。Windows EXE 当前尚无 Authenticode 发布者签名；更新清单使用 Ed25519 签名并核对包摘要。[数据访问与签名说明](../TRUST.md)。

## English

- Refine the Paper dashboard's typography and layout. Navigation, metric labels and readings use coordinated UI lettering, with more restrained numbers and more readable periods, update times and data explanations.
- Adjust type hierarchy and spacing in the Paper widget while retaining its compact/expanded views, pacing details, status explanations and independent style selection.
- Retain the journal background and palette, Clear and Meter styles, quota history, local records and existing preferences.

Choose Paper under **Settings → Appearance**. The floating widget follows the workspace by default and can use its own style under **Settings → Desktop & Codex**.

For manual upgrades, quit Pulse and back up its complete directory before replacing the program while retaining `data`. The Windows EXE currently has no Authenticode publisher signature; the update manifest uses Ed25519 and the package digest is verified. [Data access and signing details](../TRUST.md#english).
