# Codex Pulse 0.5.0

## 中文

在支持本地 MCP Apps 插件的 Codex 桌面客户端中查看 Pulse，减少在两个窗口间切换。

- **设置 → 常规 → Codex 客户端快捷入口 → 添加到 Codex**，打开原生插件安装页。
- 清爽／刻度面板显示今日 Tokens、API 参考估价、官方额度窗口剩余百分比及重置时间，支持浅色／深色和中英界面。
- 面板每分钟读取本地快照，可手动刷新、打开 Pulse 主窗和显示桌面浮窗。
- 插件模板内置于程序，更新单个 exe 后仍可重新添加入口；移动安装目录后需重新安装插件。

请保持 Pulse 运行以持续更新数据。插件自身不登录账号、不查询额度服务、不读取对话正文。无数据、陈旧数据、跨日与额度窗口到期分别处理，不把未知值显示成零或自动补满额度。API 估价不等于订阅账单或实际收费。

入口、固定方式和位置由 Codex 客户端提供；不能放到 Windows 标题栏的任意坐标。Web、移动端和普通 CLI 不提供相同的侧栏界面。组织策略可能限制本地插件。

## English

View Pulse inside a Codex desktop client that supports local MCP Apps plugins, with less switching between windows.

- **Settings → General → Codex desktop shortcut → Add to Codex** opens the native plugin installation page.
- Clear/Meter panels show today's tokens, API cost estimates, remaining quota percentages and reset times, with light/dark themes and Chinese/English UI.
- The panel reads a local snapshot every minute, with manual refresh and actions to open the Pulse dashboard or desktop widget.
- Plugin templates are embedded in the executable, including after executable-only updates. Reinstall the plugin after moving Pulse.

Keep Pulse running for updated data. The plugin does not sign in, query quota services, or read conversation bodies. Missing, stale, previous-day and expired-window values remain distinct; unknown values never become zero or reset to full capacity. Estimates are not subscription bills or actual charges.

Codex controls entry placement and pinning. Arbitrary Windows title-bar coordinates are not supported. Web, mobile and regular CLI clients do not provide the same sidebar UI. Organization policies may restrict local plugins.
