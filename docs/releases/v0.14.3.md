# Codex Pulse 0.14.3

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.14.3)

## 中文

- 配速主窗详情、浮窗和 Codex 面板移除本轮每日观测表。逐日数据可以在「用量分析 → 官方额度记录」查看。
- 额度窗口、重置时间、参考分配和费用等补充说明收进读数旁的 ⓘ。鼠标悬停、键盘聚焦或点按即可查看，按 Esc 收起说明。
- 关键读数、刷新状态和恢复入口仍可直接查看。

手动升级前请退出 Pulse，备份完整程序目录，并在替换程序时保留 `data`。应用使用 Ed25519 验证更新清单，再核对包摘要。[数据访问与签名说明](../TRUST.md)

## English

- Daily observations move out of pacing details, floating panels and the Codex panel. Find daily records in **Usage analysis → Official quota history**.
- Open an information icon beside quota, reset, allocation or cost readings by hovering, focusing or tapping it. Press Esc to dismiss the explanation.
- Key readings, refresh status and recovery controls remain visible.

For a manual upgrade, quit Pulse, back up the complete program directory and retain `data` when replacing the program. The app verifies the update manifest with Ed25519 and checks the package digest. [Data access and signing details](../TRUST.md#english)
