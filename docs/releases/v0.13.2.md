# Codex Pulse 0.13.2

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.13.2)

## 中文

- 修正纸册主题部分入口仍混用楷体、衬线体和系统字体的问题，覆盖分析、会话、模型、日/月/项目、设置、账号和详情弹层，以及标题栏配速卡、托盘与 Codex 面板。
- 中文、数字和倒计时使用协调的 UI 字体，统一页面及设置分区的标题层级，调整配速卡与托盘中过大的字样。
- 保留纸册背景、纸纹、品牌字标、清爽/刻度外观、桌面浮窗两态及已有记录和偏好。代码与原始内容继续保留等宽排版。

在 **设置 → 外观** 选择纸册。桌面浮窗可在 **设置 → 桌面与 Codex** 单独选择外观；Codex 面板也保留自己的外观选项。

手动升级前退出 Pulse 并备份完整程序目录，保留 `data` 后替换程序。Windows EXE 当前没有 Authenticode 发布者签名；更新清单使用 Ed25519 签名并核对包摘要。[数据访问与签名说明](../TRUST.md)。

## English

- Fix remaining mixtures of calligraphic, serif and UI lettering in Paper. This covers workspace views, settings, account and detail dialogs, the attached pacing card, tray and Codex panel.
- Coordinate Chinese text, numbers and countdowns with UI lettering, align page and settings-section headings, and reduce oversized text in the pacing card and tray.
- Retain the journal background, texture, wordmark, Clear/Meter styles, both desktop widget states, existing records and preferences. Code and raw content keep their monospaced formatting.

Choose Paper under **Settings → Appearance**. The desktop widget can use its own style under **Settings → Desktop & Codex**; the Codex panel also retains its own appearance choice.

For manual upgrades, quit Pulse and back up its complete directory before replacing the program while retaining `data`. The Windows EXE currently has no Authenticode publisher signature; the update manifest uses Ed25519 and the package digest is verified. [Data access and signing details](../TRUST.md#english).
