# Codex Pulse 0.8.0

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.8.0)

## 中文

- 重置服务加载失败时可定向重试，保留可用的旧读数及其失败提示，无需重新扫描本地日志；重试遵守服务请求间隔和限流。
- 明确主窗口关闭后留在托盘、桌面浮窗关闭后隐藏、右上角卡片关闭后收起，以及从托盘完全退出的区别。
- 浮窗图钉根据状态显示“置顶”或“取消置顶”，扩大按钮点击区域，保留明确的操作失败反馈。
- 设置的维护页提供安装入口检查：搬迁后查看桌面、开始菜单、登录启动和本地插件绑定及其影响，再逐项选择修复。检查只读，不自动启用原本未配置的入口，不覆盖其他有效安装。Codex 宿主缓存的插件可能仍需在其插件页重新安装。

升级保留 data 中的本地统计、偏好与同账号观测。普通检查和重试不发送模型请求。

欢迎在 [Issues](https://github.com/zhulongqihan/codex-pulse/issues) 报告问题，或在 [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions) 分享建议。

## English

- Retry a failed reset service directly without rescanning local logs. Available previous readings and their failure status remain visible. Retries respect request intervals and rate limits.
- Explain that closing the main window leaves Pulse in the tray, closing the desktop widget hides it, closing the corner card collapses it, and Quit in the tray exits the app completely.
- Name the widget pin action dynamically as Pin or Unpin and enlarge its click target while keeping action failures explicit.
- Check installation entries in Maintenance settings after relocation. Inspect desktop, Start menu, sign-in startup and local plugin bindings and their impact, then choose repairs individually. Checks are read-only, do not enable unconfigured entries and do not overwrite another valid installation. A plugin cached by the Codex host may still need reinstallation on its plugin page.

Upgrades retain local statistics, preferences and same-account observations in data. Routine checks and retries do not send model requests.

Report problems in [Issues](https://github.com/zhulongqihan/codex-pulse/issues) or share ideas in [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions).
