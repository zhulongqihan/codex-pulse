# Codex Pulse 0.4.0

## 中文

这一版优化日常查看和首次使用流程，保留清爽 Clear／刻度 Meter 两版与全部分析、回放能力。

- 首页将“本机今日用量”和“所选历史区间”分开。今日读数独立更新，查看历史日期不会改变它。
- 概览趋势默认展示完整区间，并将主要消耗来源放在一起；需要细看时仍可使用逐日明细、数据表、全屏和键盘导航。
- 悬浮窗入口直接可见，首次使用提示说明数据来源、账号额度和桌面操作。
- 窄窗口的账号区由明确操作展开，提供关闭和键盘返回，主数据不会被默认覆盖。
- 设置进入与返回位置更清楚；统一各页面的“API 估价”表述，区分参考价格、订阅账单和 Credits。
- 便携包提供创建桌面与开始菜单快捷方式的入口，移动程序后可重新创建；再次启动会找回同一数据目录的已有窗口。

Windows 10/11 x64 仍需 WebView2 Evergreen Runtime。升级时保留 `data` 文件夹。原始 Codex 日志保持只读，账号服务缺失的字段保持未知。

## English

This release improves everyday use and first-run navigation while retaining both Clear and Meter styles and the full analysis and replay workflows.

- The dashboard separates today's local activity from the selected historical range. Inspecting a historical date does not change today's figures.
- The overview fits the complete range and presents its main usage drivers together. Daily detail, the data table, full screen, and keyboard navigation remain available.
- The widget has a visible entry point. Getting-started guidance explains local sources, account capacity, and desktop actions.
- At narrow widths, account details open through an explicit control with close and keyboard-return actions; the main data is not covered by default.
- Settings have clearer arrival and return positions. “API estimate” is used consistently across pages to distinguish reference prices from subscription bills and Credits.
- The portable package includes an entry point for creating desktop and Start menu shortcuts, which can be recreated after moving the app. Opening it again restores the existing window for the same data folder.

Windows 10/11 x64 still requires the WebView2 Evergreen Runtime. Preserve the `data` folder when upgrading. Original Codex logs remain read-only, and fields unavailable from the account service remain unknown.
