# Codex Pulse 0.12.0

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.12.0)

## 中文

- 新增每日官方额度记录，分别保存周额度和短时额度的观测消耗，重置后保留历史。首页显示今日摘要，**用量分析 → 官方额度记录** 提供日期范围、窗口筛选、柱图、明细及按日分段依据。
- 默认在 Pulse 运行时后台只读采样，隐藏主窗、浮窗和标题栏后仍继续；退出或休眠时停止。**设置 → 数据来源** 可关闭新记录，已有历史保留。
- 以百分点展示可比读数的变化，分别标注未知、样本不足、未变化和断档。跨午夜无法归属的变化单独保留，不摊到某一天；同日多个实际周期可以超过 100 个百分点。
- 额度历史使用独立本地账本和固定时区，不受日志缓存重建影响。只有能够验证身份、窗口和时区的旧版部分观测会导入，不能补回未保存的历史。
- 支持独立 XLSX／Markdown 导出，包含日值、周期分段、覆盖和跨日未分配变化；不与本机 Token、API 参考成本或日志额度快照相加。
- 长消息回放先显示预览，主动展开全文；复制和搜索继续使用完整内容，原始 JSONL 与回合导航保持可用。

记录反映官方账号读数，可能包含其他设备的使用；它不是官方逐日账单。退出、休眠、断网、读数精度与周期边界都会限制覆盖。单次历史查询最多 366 天，更早历史可通过其他自定义范围查看。原有清爽／刻度和浅深模式保留。

升级保留 `data` 中的本地记录与偏好。手动升级或迁移时先退出 Pulse，备份完整程序目录，再保留 `data` 更新程序。原始会话保持只读。

Windows EXE 当前尚无 Authenticode 发布者签名；更新清单签名与包摘要验证是独立机制。[完整说明](../TRUST.md)。

## English

- Add daily official quota history for weekly and short windows, retained across resets. The dashboard shows today's summary; **Usage analysis → Official quota history** offers ranges, window filters, bars, equivalent tables and daily segment evidence.
- Background read-only recording is enabled by default while Pulse is running, including when its main window, widget and corner indicator are hidden. Quitting or sleep stops it. **Settings → Data source** can disable new recording without deleting history.
- Show comparable reading changes in percentage points, distinguishing unknown values, insufficient samples, unchanged readings and gaps. Changes spanning midnight stay unallocated; several real cycles in one day can exceed 100 points.
- Keep history in a separate local ledger with a fixed timezone, protected from log-cache rebuilds. Import only verifiable older partial observations with matching identity, windows and timezone; unrecorded history cannot be reconstructed.
- Export separate XLSX/Markdown files containing daily observations, cycle segments, coverage and unallocated cross-day changes. These are not added to local tokens, API reference costs or quota snapshots found in logs.
- Replay opens long messages as previews and expands full text on request. Copying and search retain complete content, alongside raw JSONL and turn navigation.

Official account readings may include other devices. This is not an official daily bill: quitting, sleep, connectivity, reading precision and cycle boundaries limit coverage. One history query covers up to 366 days; earlier records remain accessible through another custom range. Clear, Meter and existing light/dark modes remain available.

Upgrades retain local records and preferences in `data`. For manual upgrades or relocation, quit Pulse first, back up the complete application directory, and retain `data` while replacing the program. Original conversations remain read-only.

The Windows EXE currently has no Authenticode publisher signature. Update-manifest signatures and package digest verification are separate mechanisms. [Details](../TRUST.md#english).
