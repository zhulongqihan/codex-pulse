# Codex Pulse 0.7.2

[中文](#中文) · [English](#english) · [Download / 下载](https://github.com/zhulongqihan/codex-pulse/releases/tag/v0.7.2)

## 中文

这次更新改善配速提示与详细统计的日常使用。小窗口先显示配速结论与行动建议；“查看消耗详情”展开本轮观测依据，仍可继续查看今日 Token 和完整区间统计。展开浮窗的操作区保持可达。

主界面与伴随窗口同步成功的官方账号读数，各数据源分别判断时效。到期数值明确标为上次窗口，缺失窗口不会当作零；刷新冷却、无法估算的原因与恢复入口更清楚。插件的“重读快照”继续只读取本地快照，不触发账号请求。第三方重置预告保留醒目的来源与待确认标记。

图表区分留存前无记录与零用量，数据表随所选指标切换，同名项目使用足以区分的父路径。两版界面统一相关术语与 Token 颜色，提高关键小字的可读性；设置明确日志根目录、倒计时单位文字的预览，以及“下载更新”和“重启完成更新”两个步骤。公开演示的默认读数已统一。

保留原有数据和外观偏好。配速建议来自可用账号窗口与本机观测，不补造历史；API 参考估价不等于订阅账单。登录启动、Codex 跟随和宿主管理的插件输入区仍遵循[现有说明](../CODEX_INTEGRATION.md)。欢迎在 [Issues](https://github.com/zhulongqihan/codex-pulse/issues) 报告问题，或在 [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions) 分享使用体验。

切换账号时立即清除旧账号状态；新账号查询失败也不会继续显示旧账号的额度。0.7.2 起可显示更新失败后的已记录恢复结果与原因，并提供更新记录目录入口。若失败后恢复的是 0.7.1 或更早程序，旧界面不具备此提示，原始更新记录仍保留在数据目录中。

## English

This update improves everyday pacing guidance and detailed statistics. Compact windows show pacing conclusions and advice first. Consumption details expand the current cycle's observation basis, with today's tokens and full-range statistics still available. Expanded widget actions stay reachable.

Successful official account readings are synchronized across the workspace and companions, with freshness assessed independently for each source. Expired readings are labelled as previous-window values, missing windows remain unknown, and refresh cooldowns, unavailable estimates and recovery actions are clearer. The plugin's “Reread snapshot” action still reads local snapshots without querying an account. Third-party reset notices retain visible source and unconfirmed labels.

Charts distinguish dates before retained records from zero usage, tables follow the selected metric, and duplicate project names include enough parent path to distinguish them. Both styles share clearer terminology, consistent token colors and more readable essential small text. Settings clarify the Codex log root, countdown unit-label previews and the separate “Download update” and “Restart to finish update” steps. Default synthetic demo readings are consistent.

Previous account state is cleared immediately when changing identity, including when the new account's query fails. Version 0.7.2 and later can show the recorded outcome and reason after a failed update, with a shortcut to the update records. If recovery returns to version 0.7.1 or earlier, that older interface cannot show this notice; the raw update records remain in the data folder.

Existing data and appearance preferences are retained. Pacing advice uses available account windows and local observations without inventing history. API reference estimates are not subscription bills. Sign-in startup, Codex following and host-managed plugin input retain their [documented limits](../CODEX_INTEGRATION.md). Report problems in [Issues](https://github.com/zhulongqihan/codex-pulse/issues) or share your experience in [Discussions](https://github.com/zhulongqihan/codex-pulse/discussions).
