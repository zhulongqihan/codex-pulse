# Codex Pulse 0.3.0

## 中文

Codex Pulse 现在使用 Rust/Tauri 引擎，提供清爽 Clear 与刻度 Meter 两版完整工作台。

- 六视图、完整日期范围、独立自然月统计、完整路径项目比较、价格目录和 XLSX／Markdown 导出。
- 完整线程与父子代理导航；只读消息、工具、补丁、图片和等待回放，支持内容搜索、原始 JSONL 与定向刷新。
- 官方账号实际返回的身份、订阅、额度窗口、Credits 与 reset credits；独立的重置公告、历史、日历、预测和 Feed。逐会话 Credits 默认关闭。
- 主窗、托盘信息板与独立悬浮窗共享引擎和偏好，今日用量独立于历史查询范围。六种语言、浅深模式、密度与动效可分别设置。
- 便携数据随程序目录移动；旧版偏好按兼容项迁移。自有更新源验证签名和包摘要，失败时恢复原程序并保留数据。

下载 ZIP，完整解压后运行 `Start-Codex-Pulse.cmd` 或 `CodexPulse.exe`。需要 Windows 10/11 x64 和 WebView2 Evergreen Runtime；不需要 Node.js 或 Rust。更新旧版前退出程序，保留原 `data` 文件夹。

Token 来自本机保留日志。API 参考成本不是订阅账单或 Credits 扣款；缺价格和缺账号字段保持未知。账号与第三方重置服务可能受权限、限流或网络影响。窗口激活需要明确确认，会发出模型请求；普通刷新不会激活。

## English

Codex Pulse now uses a Rust/Tauri engine with complete Clear and Meter workspaces.

- Six views, full date ranges, independent calendar months, full-path project comparisons, a model price catalog, and XLSX/Markdown exports.
- Complete threads and parent/child agents; read-only message, tool, patch, image, and waiting activity replay, with content search, raw JSONL, and targeted refresh.
- Account identity, subscription, usage windows, Credits, and reset credits when returned by the official service; separate reset announcements, history, calendar, forecasts, and Feed. Per-session Credits remain off by default.
- The main window, tray panel, and independent widget share one engine and preferences. Today's widget values remain independent of the workspace range. Six languages, light/dark colors, density, and motion are separate settings.
- Portable data moves with the application directory, with compatible preferences imported from older versions. Pulse updates verify their own signature and package digest, restore the previous executable after a failed startup, and preserve data.

Extract the complete ZIP and run `Start-Codex-Pulse.cmd` or `CodexPulse.exe`. Windows 10/11 x64 and the WebView2 Evergreen Runtime are required; Node.js and Rust are not. Exit an older version before upgrading and preserve its `data` folder.

Token statistics depend on retained local logs. API reference costs are not subscription bills or Credits charges; unavailable prices and account fields remain unknown. Account and third-party reset services depend on permissions, rate limits, and connectivity. Window activation requires explicit confirmation and sends a model request; ordinary refresh does not.
