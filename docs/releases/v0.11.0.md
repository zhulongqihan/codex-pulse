## 中文

- 设置新增“帮助与反馈”，集中查看使用帮助、分享体验和报告问题。反馈摘要使用最少白名单字段，完整预览后再主动复制；不自动上传账号、额度、路径、会话或原始日志。
- 首次使用根据已返回的额度安排下一步：账号响应但缺少窗口时先查看账号详情；有效周窗口和零余量都不误报为没有读数。明确基本读数先可用，条件预测随后积累。
- 官网下载前说明商店版跟随、ChatGPT登录/API Key、WebView2、桌面数据访问与代码签名现状。可交互的合成工作情境演示展开、收起及离开Codex后隐藏，避免把示意当真实用户截图。
- 清爽／刻度与六种语言继续可用，原有只读日志、统计和导出不变。升级保留 `data` 中的记录、索引、偏好及同账号观测。

Windows EXE 当前尚无 Authenticode 发布者签名；更新清单签名与包摘要验证是独立机制。[完整说明](../TRUST.md)。本机Token与账号额度分别统计，API参考成本不是订阅账单，预测不保证工作时长。

欢迎在软件的帮助与反馈中告诉我们第一次使用卡在哪一步、实际工作时何处有用或干扰。请勿发送认证文件或原始会话。

## English

- Add **Help & feedback** in settings for usage guidance, experience discussions and bug reporting. A minimal allowlisted summary is fully previewed before you choose to copy it; accounts, quota, paths, conversations and raw logs are not uploaded automatically.
- Guide first use according to returned quota. An account response without windows leads to account details; a weekly-only window or zero remaining quota is still a valid reading. Basic readings are useful before a conditional forecast becomes available.
- Explain Store-client following, ChatGPT/API-key compatibility, WebView2, desktop data access and signature status before download. An interactive synthetic work scenario shows expansion, collapse and hiding away from Codex without presenting illustrations as real-user screenshots.
- Retain Clear/Meter, six languages, read-only logs, accounting and exports. Upgrades preserve records, indexes, preferences and same-account observations in `data`.

The Windows EXE currently has no Authenticode publisher signature; update-manifest signatures and package digest verification are separate mechanisms. [Details](../TRUST.md#english). Local tokens and account quotas remain separate; API reference costs are not subscription bills, and forecasts do not guarantee working time.

Use Help & feedback to share where first use became difficult or when Pulse helped or interrupted actual work. Never send authentication files or raw conversations.
