# Product

## Register

product

## Users
Windows Codex users working for long stretches who want today's usage and remaining plan capacity visible without leaving their work. Chinese-first, also welcoming English-speaking open-source users.

## Product Purpose
A local desktop companion combining an always-on-top widget with daily, model and project analytics. One launch, existing Codex sign-in, useful motion, truthful separation of account quota and locally reconstructed tokens. Source, app, runtime data and build caches live on the user's selected drive.

## Brand Personality
Precise, composed, alive. A small instrument on a busy desk, with a readable main workspace and quiet feedback as data updates.

## Anti-references
Opaque admin-key logins, menus full of unused billing features, decorative loading performances, unexplained dollar totals, repeated permission prompts, empty today's values without context. No imitation of OpenAI's official identity.

## Design Principles
- A glance should answer what remains; a click should explain where usage went.
- Keep local activity and official account limits visibly distinct.
- Changes are legible: restrained count transitions, chart interpolation, visible refresh feedback.
- User data stays on device; public demonstrations use labeled sample data only.
- One portable Windows release and exact startup instructions.

## Accessibility & Inclusion
WCAG AA contrast; complete keyboard focus, semantic controls, system fonts, reduced-motion alternatives, source labels and non-color status cues.

## Confirmed refinement

The user explicitly asks for a literary, artistic atmosphere while preserving information. Editorial typography, thoughtful rhythm and restrained atmosphere should make the app inviting at first glance. Daily totals, input/output/cache, models, projects, source timestamps, account remaining limits and reset information remain accessible and legible.
